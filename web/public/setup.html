GitHub OAuth optionnel

Protège l'interface avec une connexion GitHub. Sans ça, l'interface est accessible sans login (accès local uniquement recommandé).

Comment créer une OAuth App :
GitHub → Settings → Developer settings → OAuth Apps → New OAuth App
Homepage URL : http://VOTRE_IP:3000
Callback URL : http://VOTRE_IP:3000/auth/github/callback
Seul cet utilisateur peut lancer des actions admin.
