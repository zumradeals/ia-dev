🤖 Modèle par défaut

Le modèle sélectionné est injecté dans ~/.claude/settings.json à chaque démarrage de workspace.
Utiliser un modèle standard évite l'erreur « Usage credits required for 1M context » sur les abonnements Claude Pro.

Min 5 — Max 1440 (24h). 0 = désactivé.

⚠️ Le modèle s'applique aux workspaces au prochain démarrage. L'auto-sleep est actif immédiatement.
